## 实际执行

三个独立 Codex 子 Agent 完成软件发布工具与教育内容两类有用途任务，均为真实模型选工具、读写和执行，不是测试进程冒充 Agent。主线参与协调与审阅；本轮不是无用户消息唤醒，也不是完全无辅助自我改进实验。

| 任务 | 实际结果 | 审阅与边界 |
|---|---|---|
| 教师 | 读取新协议与CLI，在同一Markdown根建账，写可运行教材；执行无审阅、陈旧写入、哈希漂移反例并恢复原字节 | 主线核验回执和产物，早期unknown保留；独立学习者使用之前，不授予教学通过。 |
| 教育作者 | 产出正文878汉字学习卡、12项主张核查，实际查原始研究摘要并保留首次DOI 403 | 后续研究使“提取一般优于重读”的初判收窄；没有将人类结果当Agent增益。主线审阅该具体产物。 |
| 新学习者 | 实际读同根context、最新node、memory和教材，自行生成五文件清单；错误哈希被拒且不写入，再用新CLI进程恢复 | 首轮77,053字节；协调器明确通知版本变更后，另生成77,934字节新清单。两份源文件变化，旧attempt保留；29条实际子进程回执核验，主线独立重算最终五份源码。 |

学习者自行编写清单生成与流式重读程序。教材未提供完整命令捕获包装器，这是实用缺口；学习者补出包装器并保存脚本原文，不把这项实现算到教师头上。冻结教材页首仍是“待审”，更新后的项目context已指向新的审阅节点与准确教材哈希。

最终修订：教师 **6**、学习者 **3**、教育 **3**。教师teach、学习者apply只在本方法与任务范围通过；其他维度仍有未验，不标通用精通。项目context推进至 **4**。宿主原会话回执保留本地，公开衍生件去除本机路径，保留原哈希、命令身份、输出哈希及结论范围。

## 复现并修复的缺陷

| 缺陷 | 修复前实际问题 | 修复及回归 |
|---|---|---|
| 基线一项失败掩盖另一项未知 | 通用、领域及组合候选会被当作修复成功 | 未知基线优先阻止两条比较路径；两条新增回归先失败后通过。 |
| 重复证据推迟复习 | 第23小时重记旧结果，让第24小时到期变为第47小时 | 复用有效证据的原截止，不用最新重复时间续期。 |
| 失效来源仍增加连续成功 | 来源补好后的迁移错误得到3天间隔 | 失效旧记录打断连续性，新有效证据从1天重新计算。 |
| 改教材冒充新增教学证据 | 同学习者任务与产物不变，只改教师材料便延长复习 | 根据学习者的新任务、新产物计算教学间隔。 |

## 研究与交付

双语研究涵盖15组原始/官方来源、四国课程机制和大学教学方法；开源研究核查十个项目，20份固定commit的README/许可blob读回一致。部分教育来源只取得官方索引片段或摘要，文档逐项说明，不冒充全文。没有安装第三方框架或把调研称为已集成。

新增两张图各 **111节点、110连线**，真实渲染及布局核查通过，原20份图回执和40个源/SVG文件不变。视觉检查发现并修正初版重叠和保留CSS类名冲突后才接受。[图示回执](evidence/capability-learning-20261103/diagram-verification.json)、[改判记录](evidence/capability-learning-20261103/diagram-revision.txt)。

核心包 **68文件**，包含新脚本、双语运行协议与教程；完整包另有源码、测试、研究、图源、历史、团队与协议。本地打包、安装、搬迁和卸载保留记忆见[打包回执](evidence/capability-learning-20261103/package-checks.json)。最终GitHub CI与公开下载读回另绑定发布页的 [RELEASE-VERIFICATION.json](https://github.com/KarmenLoop/personal-agent-growth/releases/download/v0.5.0/RELEASE-VERIFICATION.json)，不能用本地通过代替。
