# Measured transfer acceptance · 0.7.0

[简体中文](release-0.7.0-acceptance.zh-CN.md) · [Executable tutorial](measured-learning.en.md) · [Protocol](../references/measured-learning.en.md)

This release implements held-out task registration, actual CLI Agent execution, complete trial windows, native resource records and explicit source-to-target mechanism mappings. **Both proposed strategy packages preserved artifact quality, but neither met the predeclared benefit rule. The baseline remains active.** This is a tested measurement and rejection mechanism, not a demonstrated increase in general ability or financial efficiency.

## Actual task experiment

The general/domain policy text and source-experience choices froze at 17:15:17 UTC, before independent target authoring. Primary input and evaluator manifests froze at 17:25:37 and 17:28:44; complete strategy/source/executable snapshots froze at 17:41:48, before the 17:45:29 target release. This is not a claim that complete executable snapshots preceded target authoring. The author did not read candidate policies/code, and the coordinator did not open sealed target contents before release. Released 0.6.1 was the baseline. Each task had three fresh-context repetitions per arm, with seeded order, the same CLI/model/effort/transport, a 240-second Agent limit, 24 command items and an independently invoked artifact grader. The grader's expected results were not sent to the solving Agents. All initial attempts completed before comparative outcomes were opened.

- `primary_01`: a useful audit of historical sanitized handoff exports with clearly marked controlled damage, omission and extra-file variants. All completed arms correctly delivered 19 audit rows, 16 verified declarations, one mismatch, one missing file and one unlisted file. They distinguished delivered public bytes from original-source provenance and retained `handoff_ready: false`. This does not mean the historical release was damaged.
- `primary_02`: a new scientific-data QC/import variant derived from real earlier aggregation and decimal-handling failures. The station values are explicitly fixtures, not environmental observations. All completed arms correctly delivered the row audit and nine station-days, selected current revisions before QC, weighted stations equally and preserved a null index on incomplete coverage. The two complete indices are 0.133333 and 0.233333.

There were **21 real Codex CLI invocations**: 18 planned attempts plus one entire three-arm replacement block after an observed provider-capacity failure. The interrupted attempt and the two other originals remain in operational costs; the 18 uncontaminated trials form the controlled table. No application-quality failure was reclassified as infrastructure, and no candidate was rerun merely to obtain a favorable outcome.

The prospective rule required all three artifacts to pass, at least 10% lower median native tokens and at most 10% median wall-time regression. General preparation reduced task 1's median tokens by 8.34% and time by 10.70%, missing the resource threshold; it increased task 2's tokens by 18.54%. Domain preparation increased tokens by 25.82% and 38.11%, respectively. Both domains retained quality, so passed assertions alone would have hidden the resource regression. These small samples are descriptive, not statistically established universal effects. ## Trajectories, transfer and memory

The actual domain Agents read the same genuine legacy invoice lesson used by other arms, added a source/target relationship mapping, inspected target conditions, and rejected importing the source cache diagnosis or business formula. Their saved predictions and learning notes demonstrate observed application of a conditional method. They do **not** isolate the contribution of source memory: the arms differ in a frozen instruction/code/context package. The registered conditional source ablation was not triggered because domain qualified on neither task. Neither sealed reserve was opened for a favorable retry. [Trace review](evidence/measured-learning-20261104/trace-review.json) · [Adoption decision](evidence/measured-learning-20261104/adoption-decision.json).

The [portable Markdown feedback library](examples/measured-learning/README.md) retains two proposals and four task-specific inconclusive/harmful observations. Seven actual helper invocations added, journaled and retrieved them. Negative observations concern the named whole-package result, not a universal rejection of the source lesson. The library binds the bytes of its public analysis derivative and remains separately inspectable; no hidden memory store was added. A future Agent's actual reuse is a separate acceptance step.

## Complete costs and unknowns

All 21 invocations consumed **2,772,032 known native input-plus-output tokens**; the interrupted capacity attempt returned no usage, so the real total is at least that amount. Active trial windows summed to 1,909.80 seconds; first dispatch through final delivery spanned 2,262.74 seconds. Each trial window includes copying inputs/strategy, actual Agent preparation/retrieval/tools/delivery and independent grading. Native events and monotonic clocks identify observed tool intervals. Unattributed Agent time includes network and host overhead; it is not measured model inference time. Research, review, retry and delivery subdivisions without native boundaries remain unknown rather than invented. Setup, implementation, source authoring, review, documentation and publication are separate overhead.

## Repairs and regression

Independent controlled reproductions found two genuine helper defects: late encoding/partial-write failure could poison a final immutable cost path, and an explicit causal mapping against a legacy experience could silently bypass the missing source model. Atomic exclusive publication and an explicit rejection fixed those defects. Original RED receipts and GREEN regressions remain in the trace export. Mapping preserves declared roles, directed relationships and distinct variable identities; it does not prove semantic or real causality.

Local regression passed **171 tests, zero failures and zero skips** on Python 3.12.14/macOS arm64. Frozen executable hashes stayed identical through all study invocations. Publication and Skill-format checks passed. Controller fixture tests are not Agent executions. A separate read-only reviewer recomputed the comparisons, checked native records and feedback bindings, and found an overstated freeze chronology; both reports now distinguish policy freeze from full snapshot freeze. No material findings remained. The 84-file core passed **173 ZIP/manifest checks**. 14 real local commands built and verified the delivery, installed it, moved the installation to a path containing Chinese characters and spaces, executed the cost, freeze/schedule, causal retrieval and runner-import interfaces, and uninstalled while preserving the same Markdown memory SHA-256. One coordinator invocation initially used the wrong cost-helper flags and exited 2; the original error is retained and the corrected invocation passed, without changing product code or acceptance. Cost replay is explicitly replay of native evidence, not another Agent run. [Package receipt](evidence/measured-learning-20261104/package.json).

The new English and Chinese maps were actually rendered with Mermaid 11.4.1 and Chromium, **50 nodes and 62 edges per language**, and visually inspected. All 26 prior diagram sources/SVGs remain unchanged; there are now 28. Both tutorials' six offline blocks and controlled grader checks ran successfully. Those demonstrations are synthetic; actual Agent evidence is the 21-invocation study above. ## Evidence boundary and release

[Trace export](evidence/measured-learning-20261104/trace-export.zip) contains frozen inputs/strategies, actual prompts, tool commands, Agent public responses, artifacts, original failures, native tokens and clocks. [Export manifest](evidence/measured-learning-20261104/export-manifest.json) records original/public hashes. Local paths are redacted and private reasoning items removed. The readable derivative is not a canonical replay root; original hash references may identify unredacted evidence. Unused reserves, global chat content and credentials are excluded.

The study used procedural task/answer separation and reviewed all actual command traces; no grader, other-arm or reserve read was observed. `workspace-write` did not supply an OS read-isolation boundary. These are forward held-out task observations, not adversarially secured blind trials or certification of no pretraining exposure. Follow the tutorial's stronger read-isolation requirement before claiming secure blindness.

These static tasks do not newly test an Agent withdrawing an actually self-generated wrong answer or a multi-turn insistent user. The earlier 0.6.1 pressure trajectories remain scoped historical evidence and are not relabeled as that missing self-retraction test. This release does not add Windows/Cursor Agent runs, no-message wakeups, crash/cancel recovery or delayed recall. The existing delayed-review automation and private product code were unchanged. Remote CI, public download hashes and installation receipts are recorded in the release's downloadable `RELEASE-VERIFICATION.md` after those operations complete.
