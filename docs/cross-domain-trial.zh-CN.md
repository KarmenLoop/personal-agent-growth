# 跨领域完整任务实测 · 0.4.1

[English](cross-domain-trial.md) · [测量原始摘要](evidence/cross-domain-0.4.1-results.json)

本页完整说明 2026-10-23 的两领域实验。它使用当时本地候选；0.4.1 当前发布增加文档、交接兼容与学习协议，旧包哈希和性能结论仍只归属原实验，不当作本次新增 Agent 运行。

组合策略保持六次执行的必要质量，逐任务 token 中位数之和降低 15.8%，通过事前逐任务资源约束，在该组合范围采用。只有一台 Mac、两个任务、三次重复，属于探索性证据。

## 两个真实任务与质量

**软件交接验收：** 每次对四个真实 ZIP/manifest 对完成验收卡、原始结果、完整命令/退出码、预测与复习。两对通过，一对完整检查发现三个归档/NOTICE 差异，一对在 manifest 验证阶段停止。保留未完成结果和实际原因是正确交付的一部分。基线保留先前已采用的验包能力，没有故意削弱。

**科学数据分析：** 每次导出 1990–2026 共 37 行年度数据，2026 缺失年值保持空白，计算完整十年均值及描述性 OLS 趋势，提供来源解释。原冻结数据的十年均值为 0.588°C 与 0.804°C 异常值，差为 0.216°C，1990–2025 趋势约为每十年 0.234929215°C。固定验收器用 Decimal 从冻结 CSV 独立复算；这些计算不估计不确定性、不证明因果，也不预测未来。

协调方检查全部 24 份报告与复习，所有主轮完整会话通过必要质量。这里证明质量保持，未评分为质量提升。Agent 实际读取共享经验、保存预测、调用工具/计算、检查产物并反思迁移边界。公开 JSON 保留会话 ID、用量、时刻、哈希与逐任务测量，完整原生事件仍在维护者本地。

## 什么观察改变了策略

通用版中位 token 之和减少 10.4%，但科学任务慢 23.6%，超过冻结的 20% 上限；交接耗时还含未解释的时钟差。领域版科学 token 增加约 25%，超过 15% 上限，因此没有采用整个候选。

轨迹暴露共同检索问题：有的 Agent 到经验根目录找 SKILL，或到工作目录根找策略工具。虽然后来恢复，额外读取仍计成本。Compose 保留验包器、保留正确年度数据适配器，重写索引式上下文加载，带真实记录哈希、明确入口、相关观察、采用工具绑定及接口。新组件冻结后由六个真实 Agent 会话使用；协调者的工具检查不算 Agent 通过。

一次组合科学任务又暴露两个错误：数值守卫拒绝合法 `-.17`，精确浮点相等断言拒绝正常表示。Agent 修正本地检查，保留失败，通过未变的独立验收。该次花费 479041 token、408 秒，保留在所有汇总里。没有改冻结快照或验收器来隐藏失败。

结论只支持这两个任务的组合，没有逐条隔离各提示语的因果贡献；报告写入失败恢复分支也未特意触发。

## 设计、修复与限制

三路 Probe 各跑两个任务三次，策略顺序轮换、串行执行；Compose 之后再跑六个新会话。每路相同冻结输入、任务契约和 600 秒限额，无预写答案或其他候选结果反馈。固定验收器与协调检查可观察约束；共享缓存及主机波动限制时序解释。

最初 300 秒轮次中科学会话超时、没有原生完成用量，下一会话取消；该失败轮保留，随后所有策略重新冻结为修复轮，不混算前轮成功。一个通用交接样本 UTC 约 787 秒、单调钟 284 秒，原因未知，不扣除假定停顿，不删样本，时序门槛保持未知。

可见模型配置 gpt-6.1-sol/xhigh，Codex CLI 0.163.0-alpha.10.2，无训练、微调、强化学习或参数更新；供应商权重哈希不可见。Probe 冻结哈希 `12cf2bfc7cfa55ae221fffed186e15e8dedd12ec8587be825671b197bbd6616c`，Compose 为 `9618bee9e2e36de1fe45cdd7e3c7aa03643a08114e6679f29abe1ded2297f592`。

科学数据来自 [NASA 官方 CSV](https://data.giss.nasa.gov/gistemp/tabledata_v4/GLB.Ts+dSST.csv) 与 [v4 说明](https://data.giss.nasa.gov/gistemp/data_v4.html)，2026-10-23 获取，冻结哈希 `4c64eda288bce32b8d76926278f346ecea1e53506df8ee72a3d5accb0657c416`，各会话离线使用快照。

该实验不新增 Windows、Cursor 桌面、调度、跨设备或未见第三领域验收。历史工具检查为 38 tests、25 包检查、7 个 Mermaid 解析；原候选 ZIP 哈希 `bc7945fd3d1da9d874b5a59d9a57646391ed381083a742632aea7ba2d9406862`，不等于现在发布包。
