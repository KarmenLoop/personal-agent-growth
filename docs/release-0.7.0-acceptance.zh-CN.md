# 计量迁移验收 · 0.7.0

[English](release-0.7.0-acceptance.en.md) · [可执行教程](measured-learning.zh-CN.md) · [协议](../references/measured-learning.md)

本版实现保留任务登记、真实 CLI Agent 执行、完整试次时间、原生资源记录和显式源→目标机制映射。**两份候选都保持了产物质量，但都没有达到预定收益门槛；继续保留原策略。** 验证的是测量与拒绝无收益改法的能力，不是已经提升通用能力或降低实收费用。

## 真实任务实验

通用/领域提案文本和来源经验选择于 UTC 17:15:17 冻结，早于独立目标编写。主任务输入和验收器清单分别于 17:25:37、17:28:44 冻结；完整策略/来源/可执行快照于 17:41:48 冻结，早于 17:45:29 目标发布，不能称为早于目标编写。作者未读候选提案/代码，总控在发布前未打开封存目标内容。原版为已发布 0.6.1。每个任务、每路三个新上下文重复，按种子排序；CLI、模型、推理强度与传输相同，Agent 限时 240 秒、24 个命令项，另行调用独立产物验收。解题 Agent 没有收到验收标准答案。初始尝试全部结束后才打开比较结果。

- `primary_01`：对历史脱敏交接材料做有实际用途的审计，损坏、缺失、额外文件均明确标为受控变式。所有完成的 Agent 正确交付 19 行审计，确认 16 个声明文件通过、1 个错配、1 个缺失和 1 个未列文件；区分公开交付字节与原始来源哈希，保留 `handoff_ready: false`。这不表示历史正式发布损坏。
- `primary_02`：从真实旧聚合/小数处理失败组织新的科学数据 QC 与导入变式。站点数值明确为夹具，不是环境实测。所有完成的 Agent 正确交付逐行审计和 9 个站点日；先选当前修订再筛质量、站点等权、缺站时指数为 null。两个完整日指数为 0.133333、0.233333。

共 **21 次真实 Codex CLI 调用**：18 次计划尝试，加上一次服务端容量故障后整个三路区块的 3 次替换。中断尝试及同区块另两路原尝试仍计入运行成本；18 个未受该故障污染的试次进入可比表。没有把产物失败改称基础设施故障，也没有为获得好结果重试候选。

| 任务 | 路径 | 合格产物 | 完整耗时中位数/秒 | 原生输入+输出 token 中位数 |
|---|---|---:|---:|---:|
| primary_01 | 原版 | 3/3 | 80.01 | 123,534 |
| primary_01 | 通用改法 | 3/3 | 71.45 | 113,227 |
| primary_01 | 因果迁移改法 | 3/3 | 85.97 | 155,436 |
| primary_02 | 原版 | 3/3 | 80.24 | 115,570 |
| primary_02 | 通用改法 | 3/3 | 80.73 | 136,994 |
| primary_02 | 因果迁移改法 | 3/3 | 82.35 | 159,618 |

预定标准是三个产物全部合格、原生 token 中位数至少降低 10%、耗时中位数最多退步 10%。通用改法在任务 1 的 token 降低 8.34%、耗时降低 10.70%，没有达到资源门槛；任务 2 的 token 增加 18.54%。因果迁移改法在两个任务的 token 分别增加 25.82%、38.11%。只看断言通过会掩盖这类退步。小样本只支持本组合的描述，不能证明普适效应。见[分析](evidence/measured-learning-20261104/analysis.json)、[结果表](evidence/measured-learning-20261104/task-results.csv)。

## 轨迹、迁移与记忆

领域 Agent 实际读取其他两路同样可读的真实发票旧经验，添加源/目标关系映射，核对目标条件，拒绝照搬缓存根因或业务公式。保存的预测和学习记录证明本次确实使用了条件化方法，**没有隔离证明源记忆的单独作用**：各路比较的是冻结指令/代码/上下文的整个包。领域候选两项都不合格，因此未触发预先登记的来源消融条件，也未打开保留任务追逐好结果。见[轨迹核查](evidence/measured-learning-20261104/trace-review.json)、[采用决定](evidence/measured-learning-20261104/adoption-decision.json)。

[可搬迁 Markdown 反馈库](examples/measured-learning/README.zh-CN.md)保存两份提案和四条任务级不确定/有害反馈；7 次实际工具调用完成创建、追加与检索。负面反馈只描述指定任务整个候选包的资源结果，不笼统否定源经验。库绑定公开分析衍生文件的实际字节，没有增加隐形记忆；未来 Agent 是否实际采用仍需单独留证。

## 完整成本与未知

21 次调用合计 **2,772,032 个已知原生输入+输出 token**。容量故障尝试没有返回用量，因此真实总数至少为该值。各试次活动窗口累计 1,909.80 秒，首轮派发至最后交付跨度 2,262.74 秒。每个窗口包含输入/策略复制、Agent 实际预习/检索/工具/交付和独立验收。原生事件与单调时钟标识可观察工具区间；未归因时间包含网络和宿主开销，不能称为模型推理耗时。没有原生边界的研究、审阅、重试、交付分项保留未知，不补造数字。初始化、开发、来源整理、审阅、文档和发布另记开销。

开发 Agent 与本总控的原生用量也保留在开销快照中，不分摊到某一路来美化比较：

| 开发活动 | 原生输入+输出 token | 其中缓存输入 |
|---|---:|---:|
| measured_guides | 3,779,157 | 3,541,504 |
| measurement_review | 3,059,054 | 2,931,200 |
| heldout_author | 1,359,128 | 1,244,800 |
| 总控截至快照 | 29,573,818 | 28,867,072 |

总控数截至快照右删失，发布期间仍会增长；缓存输入已包含在输入中，推理明细已包含在输出中。初始化调用另有 141,452 个已知原生 token，不混入 21 次合计；WebSocket 重连覆盖不完整，一次内置服务配置拒绝发生在 Agent 回合之前。原始事件保留。没有取得原生逐任务账单或认证服务端权重身份，**实收费用、真实模型推理耗时未知，不声称省钱**。见[开销快照](evidence/measured-learning-20261104/study-overhead.md)。

## 修复与回归

独立受控复现发现两项真实缺陷：成本文件晚期编码/部分写入失败会污染最终不可覆盖路径；对没有因果模型的旧经验给出显式映射时可能被静默绕过。已改为原子排他发布与明确拒绝，原 RED 和 GREEN 回归保留在轨迹包中。映射检查声明角色、有向关系及变量独立性，不证明语义或真实因果关系。

本机 Python 3.12.14/macOS arm64 全量回归 **171 项通过，零失败、零跳过**；研究前后执行代码哈希相同。发布检查与 Skill 格式检查通过。控制器的夹具测试不算 Agent 实跑。独立只读复核重新计算比较结果、检查原生记录及反馈绑定，发现冻结时序表述过强，现已在两种语言中区分提案冻结和完整快照冻结；未剩实质性问题。见[回归身份](evidence/measured-learning-20261104/regression--public-tests.json)、[原始输出](evidence/measured-learning-20261104/regression--public-tests.stderr)、[复核](evidence/measured-learning-20261104/review--final-review--evidence.json)。

84 文件核心包通过 **173 项 ZIP/manifest 检查**。14 条真实本机命令完成构建、校验、安装、搬迁到中文与空格路径、运行成本记录/冻结排程/因果检索/runner 导入接口，再卸载并保留相同 SHA-256 的 Markdown 记忆。总控首次成本复算误用参数退出 2；原错误保留，改正调用后通过，没有改产品代码或验收条件。成本复算明确属于原生证据重放，不是新 Agent。见[包回执](evidence/measured-learning-20261104/package.json)。

新增中英文图均使用 Mermaid 11.4.1/Chromium 实际渲染并目视检查，**每种语言 50 节点、62 条边**；原 26 份图源码/SVG 未改，现共 28 份。两种语言各 6 段离线教程及受控验收器检查实际通过；教程属于合成演示，真实 Agent 证据是上面的 21 次调用。见[图示回执](evidence/measured-learning-20261104/guides--registered-diagrams.json)、[教程检查](evidence/measured-learning-20261104/guides--documentation-final-validation.json)。

## 证据边界与发布

[轨迹导出](evidence/measured-learning-20261104/trace-export.zip)保留冻结输入/策略、真实提示、工具命令、Agent 公开回复、产物、原失败、原生用量与时钟；[清单](evidence/measured-learning-20261104/export-manifest.json)同时记录原始和公开哈希。本地路径脱敏、私有推理项移除；可读衍生包不是规范重放根，内部原哈希可能指向未脱敏字节。未暴露的保留任务、全局聊天和凭据未导出。

本次采用任务/答案流程隔离，并核查了全部实际命令轨迹，没有观察到读取验收器、其他路或保留任务。`workspace-write` 没有提供 OS 读取隔离，所以这是保留任务前向观察，不能称为对抗性安全盲测或认证模型训练中未见。需要声称安全盲测时，遵守教程更严格的读取边界要求。

这两个静态任务没有新测“撤回本 Agent 先前实际生成的错误结论”或多轮用户坚持。0.6.1 的抗迎合轨迹仍是有限历史证据，不能改称为尚缺的自我撤回测试。本版没有增加 Windows/Cursor Agent、无新消息唤醒、崩溃/取消恢复或延迟回忆证据；旧延迟复习自动化、产品代码保持原样。远程 CI、公开下载哈希与安装回执，完成后写入 Release 附件 `RELEASE-VERIFICATION.md`。
