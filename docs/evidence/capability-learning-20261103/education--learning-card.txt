# 固定权重 Agent 怎样学会一项新任务

这里的“学习”，是改善整个 Agent 做事的方法：模型参数保持不变，把查证过的知识、失败原因和操作步骤存到外部文件，下次找到相关内容，结合当前输入执行。记忆像可查阅的工作手册；写进去只是保存，找得到、用得对才可能帮助完成任务。项目没有因此证明模型智力提高。[项目说明](../../开源发布/personal-agent-growth/docs/learning-science.zh-CN.md)

先把“学会了”改成能检查的目标。例如：把一张活动时长清单统一为分钟，保留原值，明确标出单位不清的记录，输出总时长。开始前写下验收规则：一小时算六十分钟，零不是缺失；缺单位时不猜。先预测小样本的结果，再查单位规则、实际生成文件，最后打开文件核对每行和总数。这里只示范验收过程，没有声称这项任务已经跑完。

遇到错误时，先找第一处偏差。把“零分钟”丢掉，可能是把零当成空值；没读到文件，也可能是路径或权限问题。针对原因修正，再换一份输入重做。记忆应保存规则、来源、适用条件、失败和检查办法，避免只存一份漂亮答案。下一次要实际读取并应用，才能检验经验有没有用。

人类实验提供线索，不能替 Agent 验收。[词汇研究](https://pubmed.ncbi.nlm.nih.gov/18276894/)发现重复提取有利于延迟回忆；[后续研究](https://pubmed.ncbi.nlm.nih.gov/26674128/)控制间隔后，重读也有收益。[另一项实验](https://onlinelibrary.wiley.com/doi/10.1002/acp.70174)在虚构事实任务中未发现自我解释优于重读。不能把这些结果写成“多解释、隔天复习就一定让模型更强”。

判断是否真的会，要看没见过的输入和实际产物。记录任务、版本、执行者、接受过的提示，以及检查结果；让另一位检查者按原标准验收。一次成功只支持这类输入。想证明方法带来提升，还要在相同模型、工具和预算下，与原方法比较新任务表现，记录耗时；费用拿不到就写未知。

会改变判断的反例是：Agent 会说“一小时六十分钟”，也做对了旧题，但遇到“一小时三十分钟”却记成六十分钟。此时应撤回“已经会处理这类时长”的判断，保留旧成功和新失败，补组合时长规则后再测；不能靠复述正确公式把失败抹掉。

你可以独立练一次：先遮住下方检查依据，把“二十分钟、半小时、零分钟、十五”整理成原值、换算值、备注三列，再写可确定的合计。不查示例答案，先交出自己的表；如果请 Agent 做，也先保存它的首次结果。检查依据：前三项分别是二十、三十、零分钟，合计五十分钟；“十五”单位未知，应单列，不计入完整总时长。每行、合计和未知说明都对才通过这道练习。

之后换成含小时与分钟组合的新清单再做，检验能否迁移。隔一段真实时间重新完成，才有延迟复习证据；让另一位新手凭教材做成，才有教学证据。本卡只提供方法和练习，尚未证明读者或 Agent 已经掌握；到期列表也不等于系统已自动唤醒。
