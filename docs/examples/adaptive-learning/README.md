# Adaptive learning examples · 0.6.0

[简体中文](README.zh-CN.md) · [Adaptive learning guide](../../adaptive-learning.en.md)

These usable examples are Agent-produced artifacts with independent review. The English handouts and Python scripts retain the reviewed source bytes; Chinese handouts translate those instructions and keep the same commands. Use Python 3.11+ and a current skill checkout, and write each exercise into a fresh directory outside the checkout.

| Example | Instructions | Script | What it exercises |
| --- | --- | --- | --- |
| Contributor workshop | [English](workshop.en.md) · [中文](workshop.zh-CN.md) | [practice.py](practice.py) | Mechanism retrieval, a stale-revision rejection, and the separation of recorded start from actual host action |
| Uncertain-outcome recovery | [English](recovery.en.md) · [中文](recovery.zh-CN.md) | [recovery_drill.reviewed.py](recovery_drill.reviewed.py) | Pending reconciliation, rejection of a foreign start token, and inspecting a single local effect without repeating it |

Run the commands in the corresponding handout. Preserve the numbered receipts, failed attempts, generated Markdown, and actual helper hashes. Both scripts use controlled fixtures; they do not authenticate a reviewer, demonstrate human learning, or establish production recovery. The workshop's 15-minute agenda is a facilitation target. These artifacts are usable outputs, not adoption of a general PPC strategy or proof of cross-domain superiority. See [release evidence](../../release-0.6.0-acceptance.en.md) for the recorded execution and its limits.
