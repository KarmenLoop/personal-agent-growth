# 自适应学习示例 · 0.6.0

[English](README.md) · [自适应学习指南](../../adaptive-learning.zh-CN.md)

这里提供由 Agent 产出、经过独立审阅的可用示例。英文讲义和 Python 脚本保留已审阅原件的字节；中文讲义忠实翻译说明，命令保持一致。使用 Python 3.11+ 和当前 skill 代码目录，每次练习写入代码目录之外的新目录。

| 示例 | 说明 | 脚本 | 练习内容 |
| --- | --- | --- | --- |
| 贡献者工作坊 | [English](workshop.en.md) · [中文](workshop.zh-CN.md) | [practice.py](practice.py) | 机制检索、陈旧修订拒绝，以及登记启动与宿主真实动作的区别 |
| 不确定结果恢复 | [English](recovery.en.md) · [中文](recovery.zh-CN.md) | [recovery_drill.reviewed.py](recovery_drill.reviewed.py) | 待定结果核实、拒绝外来启动 token，以及只检查一次本地效果而不重复执行 |

按对应讲义运行命令，保留编号回执、失败尝试、生成的 Markdown 及实际工具哈希。两脚本使用受控样例，不认证审阅者、不证明人类学会，也不建立生产恢复结论。工作坊的 15 分钟安排是活动组织目标。这些产物可以使用，不等于采用了通用 PPC 策略，也不证明跨领域方法更优。实际执行及其限制见[发布证据](../../release-0.6.0-acceptance.zh-CN.md)。
