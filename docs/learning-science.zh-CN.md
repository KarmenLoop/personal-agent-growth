# 学习科学与课程体系设计 · 0.6.0

[English](learning-science.en.md) · [文档索引](index.zh-CN.md) · [整体架构](architecture.zh-CN.md)

研究日期：**2026 年 11 月 3 日**。本文说明能力学习设计借鉴了哪些教育思想、怎样转成 Agent 的具体行为、何时失效以及如何验收。本文不是新学习实验的结果报告，也不证明这些方法对所有模型都有增益。

## 1. 权重冻结时，究竟在改进什么

Personal Agent Growth 改进已有模型外围的提示词、工具、检索、外部记忆、评价和调度，不微调，也不通过强化学习更新权重。一次有效复习，可以让后续会话更容易找到并正确使用已有方法；这种系统行为可以验证，但不能据此声称发生了人类式记忆巩固，或模型智力得到了未测量的提升。

设计依据包括人类学习研究、官方课程体系和大学教学方法。将它们应用到 Agent 是工程假设，需要通过真实任务、未见变式、原有能力回归，以及耗时和成本核算来验证。引用知名大学或论文不能替代这些实测。

“不会→会→深入→精通→会教学→实操”表达了成长目标，但不能成为唯一的线性等级。解释、因果、执行、迁移、教学、判断分别需要证据：会讲不等于会做，会做不等于会教。实操从低风险、可检查的小任务就开始；教学也可以提前用于发现理解漏洞，不必等到声称精通后才尝试。

## 2. 课程体系首先是依赖关系

小学、初中、高中和大学提供了逐步增加复杂度的组织思路，不应用来给用户的智力贴标签，也不表示模型像儿童一样发育。下表是本项目的原创综合，不是照搬某个国家的课程。

| 教育阶段的启发 | 学习单元 | 当下就做的小实践 | 增加复杂度需要的证据 |
|---|---|---|---|
| 小学：观察、词义、例子、基本操作 | 识别对象、输入输出、单位、正例与非例 | 读取实际材料、计算一个量，或执行已授权的可逆动作 | 换一个简单例子仍能辨别，并能指出未知部分 |
| 初中：关系、变量、模型、实验 | 连接前置知识，预测改变条件的影响 | 比较两种输入或方法，检查实际结果 | 能指出支持差异的证据，并考虑替代解释 |
| 高中：形式化、组合、反证 | 组合技能，检查假设，必要时量化误差 | 独立完成多步骤任务，处理一个异常 | 未见任务达到标准，并能识别方法的失效边界 |
| 大学：专业方法、文献、研究设计 | 阅读原始来源，比较方法，设计可复现实验 | 复现一个有用途的方法，产出可复用结果 | 有可复现材料、质量/耗时/成本对照和局限说明 |
| 教学与专业实践：始终穿插 | 面向具体受众解释、诊断误解、交付和维护 | 让受教者解决新问题；读回真实交付物 | 分别验证学习效果和实际交付，两者不互相代替 |

颗粒度的停止条件是：这个单元能观察、能验证，而且能影响下一步决策。无限细拆会增加开销，也会让 Agent 忘记完整任务。练过局部技能后，必须回到技能组合和最终交付。

## 3. 比较教育机制，不给国家排万能名次

| 教育体系 | 官方材料中的具体机制 | 本项目怎样吸收 | 来源不能证明什么 |
|---|---|---|---|
| 新加坡 | 以问题解决为中心，连接概念、技能、过程、态度与元认知 | 围绕下一项任务预习，记录选用的策略和改变策略的条件 | 国家考试成绩不能证明某一种教学法的因果效果；也不能推定 Agent 具备人类态度 [E07] |
| 芬兰 | 学科教学与跨领域能力并存，并安排跨学科学习 | 保留领域基础，再验证方法能否迁移到新情境 | 跨学科项目并不意味着取消学科知识 [E08] |
| 爱沙尼亚 | 通用能力和形成性评价；基础教育与高中有不同要求 | 用具体反馈选下一道练习，保留原来的尝试与改进轨迹 | 不能由总体框架推断每所学校的实施细节或全部现行法律 [E09] |
| 日本 | 知识技能、思考判断表达、学习取向并列；重视观察实验 | 分开记录执行与判断，用实际观察检验预测 | 掌握事实不自动等于会判断；官方报告本身也列出仍需改善的学习困难 [E10] |

这些机制可以互补，但都只是待检验的设计选择。本文不评选“全球最强教育国家”，也不从 PISA 分数直接推断教育方法的因果效果。

大学层面，[MIT 的反向设计](https://tll.mit.edu/teaching-resources/course-design/backward-design/)先明确学习结果和可接受证据，再设计活动；[CMU 的学习原则](https://www.cmu.edu/teaching/principles/learning.html)区分组件技能、技能整合以及何时适用；[Harvard Project Zero 的理解教学](https://pz.gse.harvard.edu/projects/teaching-for-understanding)关注陌生情境下灵活应用。这些思想共同支持“任务契约＋依赖图＋迁移验证”，不要求 Agent 先读完一长串课程才开始工作。

## 4. 从机制到行为、证据门和失败后继

下表中的 Agent 行为属于本项目原创工程转译。来源支持教育思想，不直接证明我们的实现有效。

| 机制 | Agent 具体做什么 | 什么证据才算达到 | 失败后怎么继续 |
|---|---|---|---|
| 反向设计 [E11] | 先定义产物、验收观察、约束和预算，再选择学习材料 | 产物符合事前约定，而非事后改写的标准 | 缩小知识缺口或修产物，不修改验收迎合结果 |
| 先备知识诊断 [E12] | 执行一个有界小任务，区分概念、策略、输入、工具、环境和权限问题 | 原始回执能支持故障分类 | 修对应层再测；工具不可用不能被误判成不会知识 |
| 检索练习 [E01–E02] | 在新会话中提出可检验预测，再检索相关经验并比较 | 明确已加载什么、回忆了什么、实际引用和使用了什么 | 修检索或经验；不得为了模拟闭卷而隐藏必要约束 |
| 间隔复习 [E01] | 后续相关任务或真实宿主触发时，检查经验是否过期和仍然适用 | 实际事件身份、时间、来源版本、新结果 | 过期证据降级，针对缺口复习；文件日期不是唤醒证据 |
| 自我解释 [E03、E06、E15] | 简述机制、假设、例子和边界，再验证预测或反例 | 在解释之外，有真实观察支持 | 记录矛盾并修机制；增加篇幅不算补课 |
| 掌握与形成性反馈 [E09、E12] | 修一个明确前置缺口，再做新的等价题和完整任务 | 新题证据及完整产物都成立 | 保留原失败，换干预方式或按预算停止，不无限刷同题 |
| 认知学徒 [E04] | 先看可观察示范，再逐步减少提示和模板 | 新会话在不同输入上独立完成，并记录受过的协助 | 找到缺失步骤，只补必要支架再验证 |
| 元认知 [E07、E12] | 执行前保存预测，执行后比较差异，修改计划 | 预测时间、观察结果和改判依据可回查 | 检查不一致并改方法，不事后声称早已预见 |
| 迁移 [E08、E13] | 对齐机制与前提，在不同领域、工具或数据分布中试用 | 目标任务独立验收，并检查负迁移 | 缩小经验范围，或拒绝在该场景套用 |
| 教学 [E06、E14] | 明确受众，给解释和未见练习，检查真实回答并纠正误解 | 受教者未见答案而独立完成；人类与 Agent 分开标注 | 改讲解或练习；只写教程时，教学能力仍未验 |
| 判断 [E10、E12] | 比较方案、关键不确定性、后果和追加检查的价值 | 原判据、弃选方案、改变判断的理由都有依据 | 收集会影响决定的信息，或准确呈现仍需取舍的点 |

这里的“思考可见”指简洁、可检查的主张、假设、预测、决定与工具证据，不要求公开模型的隐藏思维链。

## 5. 费曼、解释与局限

Richard Feynman 是物理学家和教师。[《费曼物理学讲义》序言](https://www.feynmanlectures.caltech.edu/I_91.html)介绍的课程不仅包含讲授，也有讨论和实验；作者同时讨论教学尝试的不足。这不是“费曼心理学”，也不构成通用四步学习定律。

[Caltech 现行教学资源](https://ctlo.caltech.edu/aboutctlo/whoweserve/undergraduates/learning-resources/learning/power-of-teaching)建议放下笔记解释、定位漏洞、返回材料补缺，并尽可能面向真实受众。该页面明确说明其内容改编自其他学习资源。我们保留这一出处，不把所有步骤都说成费曼首创。

解释适合诊断，但不能自动证明学习。[2026 年一项预注册研究](https://onlinelibrary.wiley.com/doi/10.1002/acp.70174)让 208 名参与者学习虚构事实，报告未发现自我解释相对重读在立即测试或两周后测试中的策略优势；正确推论与表现相关。这个结果只覆盖该研究任务，不能扩大成“自我解释一律无效”。本轮读取了摘要和相关背景，没有声称完成全部方法与统计分析审查。

对 Agent，实际原则是检查“解释是否改善下一次行动”。有效就保留；只增加成本而不改善结果，就缩短或替换。不能因来源著名就把某种策略设为永远正确。

## 6. 六维能力分别留证

| 维度 | 可接受的观察 | 不足以证明的材料 |
|---|---|---|
| 解释 | 正确、符合受众基础，并能回答一个具体追问 | 流畅、长篇或术语多 |
| 因果 | 事前预测与能够区分相关解释的检验 | 事后补写的合理故事 |
| 执行 | 已授权真实动作、产物以及按标准读回 | 计划、模拟或请求已提交 |
| 迁移 | 情境有实质变化后仍能正确应用 | 仅给原例子换名字 |
| 教学 | 受教者独立完成新的相关任务 | 教者自己写讲义又自己答题 |
| 判断 | 依明确标准做决定，保留不确定性和改判条件 | 没有观察依据的自信 |

证据至少关联任务和判据 ID、适用范围、输入与产物身份、来源和环境版本、实际时间、执行者、评价者、协助情况和是否接触答案。模型自报、工具验证、独立 Agent 评价、真人反馈属于不同证据，不混成一个“通过”。

反证和过期证据不能被新成功覆盖。一个项目验证有效，不代表全领域精通。展示阶段只能概括现有证据，不覆盖六维状态，也不阻止有益的低风险实践。

## 7. 用一个任务串起完整过程

假设用户要求为一个陌生 CSV 数据集生成可验证的质量报告。以下是设计示例，不是已经跑完的实验。

1. **定义结果。** 明确报告支持什么决定、统计口径、缺失值定义、输出与预算。用户只需要一次报告时，不强迫其参加教学活动。
2. **恢复并诊断。** 读取当前项目上下文、最新节点和相关经验。如果空白字符串与数值零的含义不清，记录为语义缺口，不猜成用户偏好。
3. **有目的地预习。** 查数据字典或权威格式说明。先预测一个小输入的缺失数、重复数，再执行检查。
4. **利用真实差异。** 结果不符时检查解析、类型和过滤条件。保留失败，针对原因补课，再试一个新格式和一个反例。随后处理完整数据，读回报告的数值、范围和来源。
5. **比较改法。** 通用候选可以是“分析前固定统计契约”；领域候选可以是“改进 CSV 编码与缺失值处理”。在同一冻结输入和相同条件下分别执行，比较完整质量、耗时和成本。候选不能通过修改自己的检查器获胜。
6. **验证复用。** 新会话获得 Skill、同一记忆根和不同数据集。观察是否真正检索并正确使用经验。找不到经验就修检索入口，不能无依据地归因成概念理解差。
7. **按需验证教学。** 让另一个 Agent 或用户按讲解处理未见输入，记录谁学会了什么。不需要教学时，该维度保留未验，不阻止先交付报告。
8. **在有意义的时机复习。** 来源变化、错误复发或后续相关任务都可能触发复习。定时复习必须有实际宿主绑定与触发回执；缺少宿主则等待后续会话，不能把日期文件当执行完成。

## 8. 对实现和评价的要求

知识和经验结论继续以 Markdown 为真相源。结构化元数据用于检索，派生索引必须可重建。Markdown 可以引用原始工具回执，但不能出现两套相互冲突、都可以写入的学习结论。

活动开始前固定目标、输入身份、预期观察、失败后继、预算和停止条件。结束后区分成功、失败、运行无效和未运行。基础设施故障可能使实验无效，不能算能力通过。

评价必须覆盖完整任务：语义正确、来源准确、异常处理、可复现、符合实际用途。任务执行成本与优化开销分别报告，失败重试也计入。研究、协调和人工协助时间不能从“提速”宣称中消失；无法获得的 token 或金额标为未知。

新策略必须保留事前验收标准，并完成相应原有能力回归。只在一个项目或一种工具有效，就保留对应范围。两个领域成功，证明的是这两个领域的观察，不是通用专家能力。

日结和周结应从真实失败或预测偏差中挑选可执行改法。没有新证据时保持原状态；重写一次反思并不等于能力增长。

## 10. 自研与引用可以同时成立

本项目的能力证据模型、任务转换和评价接口，是针对现有架构的原创综合。检索练习、认知学徒、形成性评价等研究思想不是我们发明的。本文只作概述并链接出处，没有导入第三方代码、教材、课程题库或图表。

后续如采用开源组件，需记录项目、版本、许可证、引入文件和修改。公开可阅读不等于可以再分发教育材料。自研核心实现和清楚标注参考来源，应当同时做到。
