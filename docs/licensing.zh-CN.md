# 使用、修改与开源义务

[English](licensing.md)

本项目采用 **AGPL-3.0-only**，以未修改的英文 [LICENSE](../LICENSE) 原文为准；本说明是摘要，不新增许可条款。[NOTICE](../NOTICE)覆盖团队原创 Skill、参考资料、工具、测试与仓库文档；可编辑 Markdown、配置和 Python 是本项目的源码形式。

| 情形 | 协议含义 |
|---|---|
| 自用或用于付费工作 | 允许商用；使用本身不要求公开私人任务数据 |
| 仅私人修改 | 不因做了修改就必须发布 |
| 分发修改版 | 保留适用声明、标明修改及日期，对覆盖作品采用协议要求的条款，按分发形式履行对应源码义务 |
| 修改版提供远程网络交互 | 第 13 条要求向这些用户显著、免费提供该版本对应源码的获取方式 |
| 与其他项目组合 | 是否构成同一覆盖作品取决于集成；把无关程序放在同一集合不会自动使所有程序适用 AGPL |
| 发布生成产物 | 只有产物内容构成覆盖作品时才受相关条款约束；使用 Skill 不自动给所有用户文档、记录或无关项目套 AGPL |

修改后的在线服务可提供清楚可见的源码链接，但源码须完整并对应实际部署版本。协议不要求 GitHub 账号、公开 GitHub fork、向本仓库提 PR 或公开每一次私人编辑；义务面向协议规定的接收者或网络用户。
