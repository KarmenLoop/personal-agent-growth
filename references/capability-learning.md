# 能力学习、教学与实操

[English](capability-learning.en.md)

用于用户要求掌握新领域、修补反复出现的短板、形成可复用方法或教会另一执行者的任务。普通已会任务直接做；不要为了记录成长而延误交付。这里的能力指固定模型借助可检索经验、工具和任务策略获得的可观察表现，不代表权重训练或通用智力升级。

## 先确定究竟缺什么

恢复项目的 context、最新 node、约束和相关经验。把用户目标改写为可检查的产物及使用场景，保留原话中的限制。最多先找三个决定下一动作的未知：

| 缺口 | 诊断动作 | 后继 |
|---|---|---|
| 不懂概念 | 不查资料先给定义、例子和预测 | 找一手材料，解释差异，再实际应用 |
| 会复述，不会做 | 做最小真实任务，保留失败 | 分离原子技能，示例→部分提示→独立操作 |
| 会做，不知为何 | 改一个条件，预测结果并验证 | 建因果模型，记录适用条件和反例 |
| 熟悉例子，无法迁移 | 换输入、工具或领域 | 找不变量与差异；失效时缩小经验范围 |
| 讲得顺，别人不会 | 给独立执行者教材和新任务 | 看其操作和产物，修具体误解再教 |
| 方法会，环境不会 | 核实真实工具、权限、依赖和反馈 | 补适配器或环境；缺权限不叫认知失败 |
| 判断没有依据 | 写候选、证据、可能反证和动作阈值 | 选能改变决策的查询/试验，结果后改判 |

观察到 Agent 错误，不等于用户水平低。事实、解释、预测分别写，不能把频繁出现的说法当真实知识。

## 把任务拆到能检验的粒度

对关键对象回答：它是什么、由什么组成、输入输出是什么、改变由什么机制产生、需要哪些前提、有哪些约束、失败会怎样、用什么观察区分解释。只拆影响当前决定的节点；再细分不会改变工具、验证或后继时停止。

例如解释发动机，不能停在“燃油让它动”：需要连起燃料化学能、燃烧释放热、气体压力、活塞运动、连杆曲轴转矩、损耗与控制条件；再问“只加油但没有空气/压缩/点火时预测是什么”。不同发动机原理不同，先明确对象。解释正确后仍要用模型、数据或获准实验验证相应主张，不能凭比喻认定实物安全可操作。

任务依赖图记录先修关系与证据位置，不把小学/中学/大学当用户智力标签：具体例子→关系与模型→抽象及多步推理→证据评议与陌生任务→独立研究/交付。已有证据可跳过熟悉练习；不跳过关键安全条件或新环境核验。

## 一个可接续的学习单元

1. **先定验收。** 写目标、真实使用者、产物、质量条件、时间/成本上限、范围和失败条件。来源研究、产物质量、真实运行分开验收。
2. **诊断和预测。** 在看材料/答案前写当前解释、下一步、预测及不确定点。预测错了保留，不倒改成“早已知道”。不记录隐藏思维链，只保存简洁判断和可核实依据。
3. **有目的地预习。** 每份材料要解决一个命名未知；优先原始论文、官方资料和可运行例子。记录出处、日期、适用环境和矛盾。两次新增阅读不能改变动作，或达到预算，就试做。
4. **提取模型。** 用自己的话说明机制和假设，给一个正例、一个反例和一个会失败的边界。类比与事实分开。来源支持不了的地方写假设。
5. **立即应用。** 先小而真实，再撤掉提示。保存实际输入、调用、输出、产物、退出状态和耗时；未调用工具不能写“验证成功”。
6. **检验并补课。** 对照预先条件找第一处偏离，区分概念、因果、策略、检索、工具、环境、验收错误。只补能解释偏离的知识/组件，然后回到原任务；失败和未知不消失。
7. **做变式和迁移。** 换一个能检验原理的条件，预测后执行。跨领域必须指出共享机制和领域差异，不从一个例子推全部。旧能力回归独立保留。
8. **教另一执行者。** 提供先修概念、可复制步骤、反例和诊断；给新的输入，让对方独立执行。其正确复述不够，必须有合格的新产物；失败指出教材应改哪一步。
9. **完整交付。** 核对用户目标、可用性、恢复/搬迁、维护和限制。实操贯穿前面各步，完结只是整任务验收，不能等“精通”才开始做。
10. **复习与后继。** 由实际失败、来源变动、再次需要或到期触发。先闭卷提取，再看资料，再独立变式。未来复习用宿主真实调度接口登记并读回；本地 due 列表不是已唤醒。

## 多维证据，不用自信冒充精通

维护解释、应用、反例、迁移、教学、交付、延迟提取和回归等维度。每个维度可以是未验证、通过、失败或需复习，保留任务/环境范围。通过次数、阅读数量、字数和自信分数均不自动升级。

- 解释：第三方能检查概念与机制，来源可追溯。
- 应用：实际工具和产物满足事先条件。
- 深入：反事实预测与反例能排除错误机制。
- 熟练：陌生任务迁移、旧能力回归、真实延迟复习都通过。没有等到真实时间，就保持延迟门未完成。
- 教学：不同执行者在新任务上用教材做成；不能拿教师自己的重述当学习者证据。
- 交付：完整任务真实可用；局部实验不冒充上线或用户验收。

工具 [capability_ledger.py](../scripts/capability_ledger.py) 提供 Markdown 能力账本。先核对 `--help`，再按 [教程](../docs/capability-learning.zh-CN.md)初始化、写入和读取。它校验身份声明、文件哈希、时间与规则一致性；负责审阅的人或 Agent 必须另外检查实际宿主回执及内容。脚本不会证明身份真实，不会自动执行模型或创建后台定时器。

最新失败或未知使对应当前结论降级；证据文件被改动必须重新核验，不能沿用旧通过。旧失败留在历史。预习计划只读取当前相关维度和依赖，不把整个历史塞进上下文。

保存命令时，若执行 `python -` 或其他标准输入脚本，另保存实际送入的原文和哈希；只有 argv 不足以独立重放。遗失的输入不能事后重建并冒充原始输入。重复同一证据不延后复习截止；失效来源不计入连续有效练习；教学间隔依据学习者的新任务与新产物，不凭重写教材延长。

## 判断与行动的闭环

每次重要判断保存六个短项：目标、候选、关键证据、反证/未知、选择理由、何种新结果会改变动作。对研究、试做、直接执行、等待或询问用户作选择：哪一项能以最少成本消除会改变行动的未知？涉及不确定后果时先选可逆的小步；执行后实际读回。

可以自行解决的先做，只对必须由用户决定的目标、偏好或授权取舍联系。用户沉默不证明闲暇，也不创造权限。发现环境缺失、证据冲突或预算耗尽时保留下一动作；“更聪明”不能把未知效果重复执行。

## 和双层递归配合

能力诊断产生通用改法与领域改法，但仍进入原来的 [PPC 协议](recursive-improvement.md)。冻结输入、原质量标准、模型配置、预算和基线；两个候选各跑完整任务。解释、工具、检索、提示和项目自有脚手架可以在授权范围改写，宿主权限、验收和真实来源不能为候选放宽。

组合产生新行为就重新跑。任务内修补落到当前项目；跨任务采用必须有真实迁移和原能力回归。portfolio 清单只是计划，比较器不会凭清单认证所有任务实际执行；核查逐任务原始回执，缺少时禁止宣称元能力已通过。成本未知保留 null，整个 Agent 的预习、失败、修复、教学与验证成本都纳入，不以检查器调用数替代。

先写候选经验，包含触发、机制、做法、反例、原任务证据、失效条件、下次检验和回退。下个任务必须实际读取后使用或拒绝，经验不是存进去就变成能力。

## 研究与独立实现

教育方法和开源项目用于提出机制假设。来源的效果不等于本系统效果；人类间隔学习证据不证明冻结权重模型在睡眠中巩固知识。费曼是物理学家，解释性练习不作为万能“费曼心理学”定律。参照 [教育研究](../docs/learning-science.zh-CN.md) 与 [开源互操作研究](../docs/open-source-research.zh-CN.md)。独立编写我们的协议和代码，注明外部思想；采用第三方代码时按其许可证处理，不能改名宣称纯自研。
